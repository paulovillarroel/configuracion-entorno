<Callout type="info" title="¿Qué es Node.js y por qué lo necesitamos?">
  **Node.js** es un motor de JavaScript que funciona fuera del navegador. Muchas herramientas modernas de desarrollo y utilidades de línea de comandos —incluidas varias extensiones que se conectan a los agentes de IA— se distribuyen como paquetes de Node. **NVM** (Node Version Manager) te permite instalar y cambiar versiones de Node sin permisos de administrador — evitando conflictos y errores de permisos.
</Callout>

### 1. Instalar NVM

Ejecuta en tu terminal:

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
```

<Callout type="warning" title="Importante">
  Cierra y abre tu terminal para que el comando `nvm` esté disponible.

  <OsTabs>
    <Fragment slot="win">
      <p class="text-xs mt-1">En WSL: cierra la ventana de Ubuntu (la X) y búscala de nuevo en el menú Inicio → "Ubuntu".</p>
    </Fragment>
    <Fragment slot="mac">
      <p class="text-xs mt-1">En Mac: cierra Terminal (Cmd+Q) y ábrela de nuevo.</p>
    </Fragment>
  </OsTabs>
</Callout>

Verifica que NVM se instaló correctamente:

```bash
nvm --version
```

Si muestra un número (ej: `0.40.1`), todo bien. Si dice "command not found", cierra y abre la terminal de nuevo.

### 2. Instalar Node

```bash
nvm install --lts
```

<Callout type="warning" title="En Mac con macOS 12 Monterey o 13.0-13.4: usa Node 22">
  NVM no tiene requisitos de sistema, pero **el Node que descarga sí**. La versión LTS actual (Node 24) está compilada para **macOS 13.5 o superior** — en un sistema anterior se instala pero no arranca.

  Si tu Mac es anterior a 13.5, instala la LTS previa, que funciona desde macOS 11:

```bash
nvm install 22
nvm alias default 22
```

  Para el curso da exactamente lo mismo: no usamos ninguna característica exclusiva de Node 24.
</Callout>

Verifica la instalación:

```bash
node --version
npm --version
```

Ambos deben mostrar un número de versión.
