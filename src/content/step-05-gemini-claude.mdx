<Callout type="info" title="¿Qué son los agentes de IA en terminal?">
  Son herramientas que te permiten usar inteligencia artificial directamente desde la terminal, sin abrir un navegador. Pueden leer tu código, sugerir cambios, ejecutar comandos y ayudarte a programar más rápido. Se instalan como **programas independientes**, cada uno con su propio instalador.
</Callout>

<Callout type="warning" title="Importante: la IA no reemplaza aprender a programar">
  Usar IA generativa como asistente es una excelente idea... si ya sabes programar. Si estás comenzando, puede ser contraproducente: obtienes código que funciona pero no entiendes, y eso frena tu aprendizaje real.

  **Si estás empezando:**
  - Úsala para **pedir explicaciones** ("¿qué hace este código?", "¿por qué da este error?")
  - Úsala como **guía conceptual**, no como generador de soluciones
  - Escribe tú el código, aunque sea más lento y cometas errores — ahí está el aprendizaje

  **Generar código con IA solo tiene sentido cuando ya sabes evaluar si lo que genera es correcto, seguro y adecuado para tu contexto.** Llegar a ese punto toma tiempo y práctica. No hay atajos.
</Callout>

<Callout type="tip" title="Si un tutorial menciona «Gemini CLI», usa Antigravity CLI">
  En **junio de 2026** Google retiró **Gemini CLI** para las cuentas individuales y lo reemplazó por **Antigravity CLI**, su nuevo agente de terminal. Cambiaron el instalador (ya no se usa `npm`) y el comando: donde antes escribías `gemini`, ahora escribes `agy`. Si sigues un video o tutorial más antiguo, tenlo presente — aquí ya usamos la versión nueva. → [Anuncio oficial de Google](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)
</Callout>

### 1. Instalar las herramientas

**Antigravity CLI** ([documentación oficial](https://antigravity.google/docs/cli/getting-started)) es el agente de terminal de Google. Se instala con un solo comando en tu terminal (macOS, Linux o la Ubuntu de WSL):

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

**Claude Code** ([documentación oficial](https://code.claude.com/docs/en/overview)):

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Cierra y vuelve a abrir la terminal para que los comandos `agy` y `claude` queden disponibles. Comprueba que Antigravity CLI quedó bien instalado:

```bash
agy --version
```

### 2. Configurar Antigravity CLI

Antigravity CLI es **gratuito con tu cuenta de Google** para uso individual. Si necesitas más cuota, Google ofrece planes de pago (**Google AI Pro** y **Ultra**).

<div class="not-prose my-6 bg-blue-50 dark:bg-blue-950/30 p-4 rounded border border-blue-200 dark:border-blue-800">
  <p class="text-sm text-blue-800 dark:text-blue-200 font-bold mb-2">✨ Autenticación</p>
  <p class="text-sm text-blue-700 dark:text-blue-300 mb-2">La primera vez, ejecuta <code>agy</code> y elige la opción <strong>Google OAuth</strong>. Se abrirá el navegador para iniciar sesión con tu cuenta de Google; copia el código que aparece, pégalo en la terminal, elige un tema de colores y acepta los términos. Listo.</p>
</div>

```bash
agy
```

Ya puedes conversar con el agente desde la terminal. Escribe `/help` para ver los comandos disponibles y `/quit` (o presiona `Ctrl+D` dos veces) para salir.

**Pruébalo con un prompt real** — sin entrar al modo interactivo, con la opción `-p`:

```bash
agy -p "Actúa como un experto en salud pública y resume los beneficios de usar R para análisis epidemiológico."
```
